# Citizen token prompts (ArtCraft)

Style line, put at the start of every prompt:

> Cloisonne enamel charm, thin raised polished gold wire outlining every shape, flat glossy enamel fills, one soft highlight, chunky cute chibi proportions, clean game icon, centered, plain flat white background, no text, no letters, no logo, no shadow on the background.

Order: make `healthy idle` first using `art/reference/citizen-guide.png` as the reference image. Once you like it, use that healthy idle as the reference image for every other prompt so all tokens match. For blink and reaction frames, use that state's idle as the reference and ask for the same framing.

Save each pick in `art/inbox/` as `faces-<state>-<frame>.png`.
