# Prologue painting prompts (ArtCraft)

Style line, put at the start of every prompt:

> Cloisonne enamel plaque painting, thin raised polished gold wire outlining every shape, flat glossy enamel fills with soft highlights, deep indigo night sky (#12354e to #051230), gold wire stars, Japanese decorative feel inspired by Wada Sanzo colour pairs, storybook, hopeful, square composition, the picture fills the whole frame, no text, no letters, no logo.

Make `peace` first, then use it as the reference image for the rest so the set matches (`begin` should reuse `peace` almost exactly). Save picks in `art/inbox/` as `prologue-<card>.png`.
